# Project Intelligence Skill 🧠

An MCP server that provides intelligent project analysis with:

## Features

### 1. `suggest_next_actions`
Analyzes your codebase and suggests 4-5 high-impact next actions with ready-to-use prompts covering:
- 🛡️ Security vulnerabilities and hardening
- 🧪 Testing gaps and setup
- 🚀 Deployment and CI/CD
- 🎨 UI/UX improvements
- ⚡ Performance optimizations
- 📊 Monitoring and observability
- 📚 Documentation gaps

### 2. `generate_strategic_questions`
Generates relevant questions in three modes:
- **Planning**: Architecture and strategy questions
- **Agent**: Implementation clarification questions  
- **Asking**: Requirements discovery questions

### 3. `generate_plan`
Creates phased implementation plans with risks and mitigations.
